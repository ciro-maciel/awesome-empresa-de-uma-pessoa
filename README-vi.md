## Để suy nghĩ về công việc kinh doanh

## Nhãn

Mỗi mục đều nói rõ nó là gì. Các nhãn bên cạnh giúp bạn chọn: chính thức khi do đơn vị định ra chuẩn cung cấp, mã nguồn mở khi mã được công bố, miễn phí hoặc trả phí theo cách sử dụng, API và SDK theo cách tích hợp.
