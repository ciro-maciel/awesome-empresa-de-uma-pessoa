## Para pensar el negocio

Quien ya manejó un negocio pequeño y rentable, y cómo.

- [Getting Real](https://go.mymarketing.click/umap-getting-real) - El libro de Basecamp sobre construir menos, más rápido y con un equipo pequeño, abierto en el sitio. `gratis`
- [MAKE](https://go.mymarketing.click/umap-make) - El libro de Pieter Levels sobre crear y vender productos solo, sin inversionista. `de pago`
- [Pieter Levels no podcast de Lex Fridman](https://go.mymarketing.click/umap-pieter-levels-no-podcast-de-lex-fri) - La transcripción de la charla sobre las empresas que él maneja solo. `gratis`
- [Cointeligência](https://go.mymarketing.click/umap-cointeligencia) - Ethan Mollick sobre trabajar con la IA como colega. Intrínseca. `de pago`

## Agentes de IA

Lo que hace el trabajo de un equipo.

- [Claude Code](https://go.mymarketing.click/umap-claude-code) - El agente de Anthropic que trabaja en la terminal y el editor, con documentación en portugués. `oficial` `de pago`
- [Building effective agents](https://go.mymarketing.click/umap-building-effective-agents) - El texto de Anthropic sobre cuándo usar un flujo fijo y cuándo usar un agente. `oficial` `gratis`
- [Writing tools for agents](https://go.mymarketing.click/umap-writing-tools-for-agents) - Cómo escribir herramientas que un agente usa bien, de Anthropic. `oficial` `gratis`
- [Model Context Protocol](https://go.mymarketing.click/umap-model-context-protocol) - El protocolo abierto que conecta agentes con herramientas y datos. `gratis` `código abierto`
- [CCM Stack](https://go.mymarketing.click/umap-ccm-stack) - Plugin para el agente con principios, hooks que rechazan el error conocido y skills para publicar, medir y vender. `código abierto` `gratis` `del autor`

## Etiquetas

Cada ítem dice qué es. Las etiquetas al lado ayudan a elegir: oficial cuando viene de quien define el estándar, código abierto cuando el código está publicado, gratis o de pago según el modelo de uso, API y SDK según la forma de integrarlo.
