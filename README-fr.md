Pour celles et ceux qui gèrent une entreprise seuls et veulent que des agents IA fassent le travail d'une équipe. Suit l'ordre de l'entreprise : réfléchir, mettre en ligne, facturer, mesurer, connaître le client, faire connaître et se faire trouver. À chaque étape, il y a ce que fait l'auteur de la liste et au moins une alternative d'une autre entreprise.

## Étiquettes

Chaque élément dit ce qu'il est. Les étiquettes à côté aident à choisir : officiel quand il vient de celui qui définit le standard, open source quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la manière de l'intégrer. Les éléments avec l'étiquette "de l'auteur" sont faits par Ciro Cesar Maciel et suivent les mêmes règles que tous les autres.
