## 事業を考えるため

小さく利益の出る事業を運営してきた人と、そのやり方。

- [MAKE](https://go.mymarketing.click/umap-make) - Pieter Levelsの本。投資家なしで一人で製品を作って売ることについて。 `有料`
- [Pieter Levels no podcast de Lex Fridman](https://go.mymarketing.click/umap-pieter-levels-no-podcast-de-lex-fri) - 彼が一人で運営している会社について話した対談の書き起こし。 `無料`
- [Cointeligência](https://go.mymarketing.click/umap-cointeligencia) - Ethan Mollick：AIを同僚として働かせる方法。Intrínseca。 `有料`
